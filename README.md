# 小橙子-一键又一键

一个糖果色、立体可爱画风的**点击式箭头解谜小游戏**，使用 Python + Pygame 实现。
全部图形与音效均由程序实时绘制 / 合成，**不依赖任何外部素材**，克隆即可运行。

---

## 一、游戏玩法

棋盘上散布着朝上、下、左、右四个方向的箭头：

1. 点击一支箭头，检查它**前进方向（同行或同列）直到棋盘边界**的所有格子；
2. 如果路径上没有其它箭头，它就会加速飞出棋盘并消失；
3. 如果被挡住，箭头会晃动、闪红提示，并消耗一次爱心（失误机会）；
4. **清空全部箭头即通关**；爱心用完或倒计时归零则失败。

每关通关后会按失误情况评定 1~3 星（一次不碰撞即 3 星），剩余时间也会折算成奖励分。

## 二、功能特性

- 完整界面流程：开始页、玩法说明、选关、游戏、暂停、通关 / 失败结算；
- 6 个精心设计的关卡（4×4 → 7×7，难度递增），另有**随机挑战无尽模式**；
- **逆向构造式关卡生成**：随机关卡在数学上保证 100% 可通关；
- 丰富的游戏反馈：飞出加速 + 残影、碰撞震屏 + 闪红 + 粒子、连击加分、得分浮字；
- 通关结算：星星逐颗弹出、彩带雨、星级与最高分本地存档（`save.json`）；
- 每关倒计时，最后 10 秒屏幕边缘红色脉动报警 + 滴答声；
- 辅助功能：每关 3 次「提示」（DFS 求解器给出必胜一步）、「撤销」反悔；
- 程序合成音效与背景音乐（numpy 生成波形），支持一键静音；
- 果冻质感 UI：投影、渐变、高光、悬浮放大，糖果配色，箭头自带小表情。

## 六、核心设计说明

### 1. 逻辑与界面分离

所有规则（路径检测、失误判定、计分、胜负）都在不依赖 pygame 的 `model.py` 中，
界面层只负责绘制和把鼠标点击翻译成 `session.click(row, col)`，
因此核心逻辑可以直接用 `unittest` 自动化测试，无需打开窗口。

### 2. 路径检测

用枚举 `Direction` 表示四方向（值为行、列位移），点击后沿方向逐格前进直到边界：

```python
def path_clear(self, arrow) -> bool:
    for r, c in self.iter_path(arrow):
        if self.grid[r][c] is not None:
            return False
    return True
```

走到边界自然停止，不会越界；只有同一直线上的箭头才算阻挡。

### 3. 逆向构造关卡（保证有解）

正向「随机摆箭头再验证」容易生成死局。本项目采用**逆向构造**：
设清除顺序为 a1 → a2 → … → an，**倒着摆放**——先摆 an，最后摆 a1。
摆 ai 时棋盘上只有排在其后的箭头，只需保证「新箭头前进方向的射线为空」，
那么按摆放顺序的逆序点击就必然通关，从数学上杜绝死局。

### 4. DFS 求解器与提示

`levels.solve()` 使用记忆化深度优先搜索，返回一条「每步都前方无阻挡」的
消除顺序，既用于关卡可解性验证，也用于游戏内「提示」功能给出必胜一步。

### 5. 程序合成音效

`sounds.py` 用 numpy 生成正弦 / 三角波、滑音与噪声，并加上包络混音，
再交给 `pygame.mixer` 播放：飞出上扬音、碰撞闷响、通关琶音、倒计时滴答、
循环背景音乐等全部实时合成，仓库内没有任何音频文件。
